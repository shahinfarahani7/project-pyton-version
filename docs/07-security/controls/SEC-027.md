# SEC-027: Replay Protection

## Requirement
EdgeMint shall enforce replay protection. This control is mandatory for production unless a time-bounded, owner-approved risk acceptance exists.

## Verification evidence
Automated test or configuration scan, deployment evidence, audit sample, owner, review date, failure alert, and rollback procedure.

## Failure behavior
Fail closed for authentication, authorization, financial mutation, token claim, tenant boundary, model integrity and stale assignment completion. For availability-only controls, degrade according to the documented runbook without weakening data or money integrity.

## Acceptance
A negative test proves the prohibited path fails; a positive test proves the allowed path succeeds; logs contain request and trace IDs but no secrets or raw customer payload.
