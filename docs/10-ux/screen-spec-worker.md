# Worker Screen Specification

## Home/Mine
Minty scene, a clear `Available / Unavailable` control, device readiness, current mission and three earnings balances. Setting `Available` authorizes compatible automatic assignment under the current consent. Idle scene consumes minimal GPU/CPU and does not imply active paid compute.

## Assigned mission
The current mission appears after the server auto-leases it and execution starts automatically after native validation. Show task category, privacy label, model, estimated duration/data/energy/reward, deadline and start status. Never show Accept or Reject controls. Sensitive customer identity is never shown.

## Active mission
Real progress, thermal/battery state, safe-stop/checkpoint rules, foreground indicator and diagnostics. Reward remains estimated. Local environmental failure is machine-reported automatically; it is not a user rejection.

## Earnings
Accrual line items, quality modifiers, hold reason/expiry, claim eligibility and conversion disclosure.

## Models
Artifact size, free storage, compatibility, license notice, download/resume/delete and verified digest.
