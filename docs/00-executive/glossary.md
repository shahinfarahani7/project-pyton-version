# Canonical Glossary

| Term | Exact meaning |
|---|---|
| Compute Credit | non-transferable customer prepaid service balance, accounted in EUR micros |
| Reward Micros | verified worker payable in EUR micros; not a token and not transferable |
| EDGE | optional utility token used only after claim eligibility and claim-epoch conversion |
| Passive Reward | capped availability stipend funded by a promotion budget; not mining and not guaranteed |
| Task | stable customer request identity |
| Revision | immutable version of task input/configuration |
| Attempt | logical try to execute a revision |
| Offer | expiring proposal sent to a worker |
| Lease | exclusive execution authority with a fencing token |
| Verification | quality and integrity decision over submitted results |
| Consensus | comparison of independent results satisfying anti-affinity rules |
| Cloud fallback | controlled execution on approved cloud capacity when edge SLA cannot be met |
| Policy hash | SHA-256 of canonical policy JSON used for audit and replay |
| Quote | immutable price and cost estimate valid until expiry |
| Claim epoch | approved interval with conversion rate, treasury cap and compliance snapshot |
