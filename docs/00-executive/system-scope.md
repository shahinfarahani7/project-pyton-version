# System Scope

## In scope for initial commercial release

- Public marketing site and developer documentation.
- Customer organization/workspace/team/API-key administration.
- Asynchronous task API, file ingestion, webhooks and SDK contracts.
- OCR, document extraction, image analysis, speech transcription, translation, generation and embeddings through an approved model catalog.
- Flutter worker application with explicit user consent, model manager, task execution, checkpointing, earnings and gamification.
- Edge-preferred routing with cloud fallback.
- Usage billing, subscriptions, prepaid balance, invoices, refunds and disputes.
- Off-chain worker rewards and gated token claims.
- Operations console, audit, fraud review, reconciliation and SRE controls.

## Out of scope until separate gates

- Public token sale.
- permissionless model publication.
- training or fine-tuning on worker devices.
- splitting one inference across multiple consumer phones.
- hidden background compute.
- gambling, chance-based rewards or guaranteed return language.
- automatic legal/tax conclusions for every jurisdiction.
