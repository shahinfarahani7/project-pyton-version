# Production Gates

## Gate A — Paid API
- API contracts validated and versioned.
- Idempotency, outbox, ledger and tenant isolation tests pass.
- Worker result treated as untrusted.
- Cloud fallback and customer execution policy implemented.

## Gate B — Worker rewards
- Fraud controls, hold periods, appeal and reconciliation operational.
- Passive program has hard budget and kill switch.
- Store metadata does not describe on-device cryptocurrency mining.

## Gate C — Token claim
- Legal, compliance, tax, accounting and smart contract audits approved.
- KYC/AML and jurisdiction matrix enforced.
- Off-chain liabilities reconcile to claim batch and chain transaction.

## Gate D — Public offer
- White paper and marketing controls approved for every target jurisdiction.
- No future-value or guaranteed-return claim exists.
- Incident freeze and treasury runway controls tested.
