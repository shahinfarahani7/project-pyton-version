# Public Site Specification

## Primary journeys
- understand EdgeMint value and supported task types.
- compare pricing and verification levels.
- read security/privacy architecture.
- register, request enterprise demo or open developer docs.
- learn how worker participation operates without crypto-mining claims.

## Required routes
`/`, `/how-it-works`, `/use-cases`, `/pricing`, `/models`, `/security`, `/workers`, `/developers`, `/docs`, `/status`, `/legal/*`, `/contact`, `/login`, `/register`.

## Production requirements
- localized FA/EN content, canonical URLs, sitemap, structured metadata and accessibility WCAG 2.2 AA target.
- pricing content is generated from published Offer/PriceBook snapshots.
- status data comes from a separate status system.
- worker marketing discloses battery/data controls, variable task availability and non-guaranteed rewards.
- no investment-return or on-device cryptocurrency-mining language.
