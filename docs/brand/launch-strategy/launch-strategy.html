01 · Starting point

What we are introducing

FibonAI is an edge-first AI inference platform. Customers submit document, image, language and audio tasks. Each task gets a fixed EUR quote before it runs, then executes on opted-in devices running signed models, with cloud used only when policy allows and the reason recorded. Everything is written to an audit trail.

This page is internal

The paragraph above is the whole product. It is here so the team understands what we hold back. Do not publish it in Phase 1.

Five rules for every piece we publish

1. One idea per phase

Each phase has a single message. If a post needs two ideas, it belongs to a later phase.

2. Only true claims

Say only what the product docs support. No performance numbers, customer names or dates that have not been approved.

3. The website is the style guide

Colours, fonts, glass objects and layout come from the marketing site and docs/brand/DESIGN.md. No new palettes per post.

4. Real objects, glass style

Phone, chip, padlock — realistic and frosted. No cartoons, coins, mining rigs or sci-fi holograms.

5. Nothing goes out without the weekly review

All three members check every asset against the checklist on page 9. An asset that fails is fixed, not published "for now".

04 · Phases 2 and 3

Explain the flow, then open the whole product

02

How it works

Message: submit a task, get a fixed EUR quote, it runs on an edge device, the result comes back.

  • Animate the four steps of the website's workflow section — one short clip per step and one combined explainer.
  • One worked example using a published rate exactly as written, e.g. Document OCR · €0.0025 per page. Never round or invent prices.
  • Introduce region policy and "cloud only when allowed, reason recorded".
  • Reveal the full marketing website at the end of the phase.
03

Launch — two audiences

Customers
  • Use cases: documents, vision, language
  • Published price table
  • Verification tiers and audit trail
  • Customer portal and developer API
Workers
  • Opt-in device participation
  • Signed models, device safety
  • Rewards are variable, not guaranteed
  • "Not cryptocurrency mining" on every worker asset

Keep the two audiences in separate assets. A worker message must never appear inside a customer ad, and the other way round.

05 · Team

Three roles, built around who knows motion

Only the motion lead edits video. The other two members produce static and written work, and use templates the motion lead prepares — they never animate from scratch.

Member 1

Motion lead

Knows video editing and motion graphics

  • Logo motions and all video
  • Builds editable templates: end card, lower third, caption style
  • Exports every size
  • Owns motion rules (page 8)
Member 2

Visual designer

Static design, no motion needed

  • Key visuals and post layouts
  • Profile/cover images
  • Website and holding page
  • Keeps the shared template file tidy
Member 3

Copy & review

Words, schedule, quality

  • All text and captions
  • Checks claims against the docs
  • Posting calendar
  • Runs the weekly review

Proportion on a typical frame: about 85% canvas and panels, 10% white/grey text, 5% gold. Gold marks one key word or the mark — never whole backgrounds.

Type

Cal Sans — headlines only, one line, at most 7 words.

Geist — body, captions, buttons.

Geist Mono — prices, task names, small labels.

Layout

  • Wide margins, one headline, one object.
  • Rounded cards (14–16 px), thin light borders, no drop shadows.
  • Pill buttons: white with dark text.
  • One highlighted word in the gold gradient per headline.

3D and imagery

  • Frosted-glass phone, chip, padlock with titanium edges.
  • Soft cool rim light, warm gold rim; dark background.
  • Objects can float slowly; never spin fast.

Never

  • Recoloured or stretched mark, mark with glow or shadow
  • Blue neon, holograms, coins, mining hardware
  • Stock photos of people pointing at screens
  • More than one gold word per headline

07 · Motion

Motion rules and logo motion review

Feel

  • Calm and precise: ease-out curves (website uses cubic-bezier(0.22, 1, 0.36, 1)).
  • Short moves, then hold. Text stays still long enough to read twice.
  • Hard cuts or short fades; no spins, flips, glitches or bounces.

Recommended timings

  • Logo intro: 2–3 s, last 0.5 s held still
  • End card: 1.5–2 s
  • Text in: 0.3–0.6 s
  • Minimum on-screen text time: 2 s per line

Starting values for the team, to be tuned by the motion lead.

Weekly review checklist

  • Belongs to the current phase — reveals nothing held back
  • One message only
  • Colours and fonts from page 7
  • Mark used correctly, enough space around it
  • Prices exactly as published, in EUR
  • No claims missing from the product docs
  • Text readable on a phone screen

Files and naming

docs/brand/
  motion/   logo motions, templates
  phase-1/  final exports
  phase-2/
  phase-3/

Name files as phase_topic_format_v01, e.g. p1_teaser_9x16_v03.mp4. Never overwrite an approved version — bump the number.

Open items before Phase 1 starts

  • Share both logo motions for review.
  • Confirm the FibonAI domain — site emails still use the old domain.
  • Get the wordmark as a vector file for large formats.
  • Decide channels and the start date (team decision, not set in this document).
